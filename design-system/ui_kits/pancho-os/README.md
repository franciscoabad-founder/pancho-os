# Pancho OS UI kit

Click-through recreation of the Pancho OS cockpit: sidebar navigation between Hoy (dashboard), Tareas, Hábitos & Salud, and Finanzas. Built from the brand-guidelines-only source (no attached codebase/Figma) — screens are original layouts composed from the authored primitives (Card, MetricCard, ProgressBar, Checkbox, Tabs, Badge, Switch, Button), not a copy of an existing product screen.

Files: `index.html` (shell + mount), `Sidebar.jsx`, `Dashboard.jsx`, `Tasks.jsx`, `Habits.jsx`, `Finance.jsx`.
